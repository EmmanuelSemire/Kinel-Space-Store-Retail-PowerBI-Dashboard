# 🛒 Kinel Space Store: Retail & E-Commerce Analytics Dashboard

An executive-grade Power BI retail analytics solution designed to track sales performance, supply chain logistics, and regional market distribution across Nigeria.

## 📊 Key Metrics & Highlights
* **Total Sales:** $2.3M
* **Total Profit:** $286.4K
* **Geographical Footprint:** 49 States & 531 Cities
* **Logistics & Ship Modes:** Evaluates Standard Class, Second Class, First Class, and Same Day distribution trends.
* **Customer Segments:** Analyzes Consumer, Corporate, and Home Office purchasing behaviors.
